# Оникс

Лаунчер Minecraft: Java Edition на Electron. Тёмно-красное самурайское оформление, сборки с закреплением, вход сразу в мир или на сервер, скины, моды и сборки с Modrinth и CurseForge.

## Возможности

- **Аккаунты**
  - Лицензия: официальный вход Microsoft → Xbox Live → Minecraft Services. Токены обновляются сами и хранятся зашифрованными.
  - Ely.by: «пиратский» аккаунт со скином. Игра запускается через authlib-injector, поэтому скин с Ely.by виден в игре.
  - Офлайн: только ник, UUID как у серверов в offline-mode.
- **Скины**: для лицензии загрузка PNG, выбор модели (обычная или тонкая) и сброс прямо в лаунчере; для Ely.by превью и переход на сайт для смены скина.
- **Сборки**: отдельная папка на каждую, закрепление в боковой панели, цвет значка, память, аргументы JVM, своя Java.
- **Вход в мир и на сервер**: вкладки «Миры» и «Серверы». Миры берутся из папки saves, серверы из servers.dat плюс свои; для серверов показывается онлайн, пинг и описание. Вход сразу в мир работает с Minecraft 1.20 и новее.
- **Загрузчики**: Vanilla, Fabric, Quilt, Forge, NeoForge. Forge и NeoForge ставятся официальным установщиком в папку лаунчера.
- **Java ставится сама** по официальным данным Mojang.
- **Каталог**: Modrinth и CurseForge (моды, сборки, ресурспаки, шейдеры), установка вместе с зависимостями, установка сборок целиком (.mrpack и CurseForge).
- **Фильтры каталога**: боковая панель со сворачиваемыми разделами «Версия игры» (поиск, показ снапшотов), «Загрузчик», «Категория», «Среда», «Лицензия». Категории и загрузчики зависят от типа (моды, сборки, ресурспаки, шейдеры) и берутся из тегов Modrinth, без сети работает встроенный набор. Для CurseForge действуют версия и загрузчик.
- **Настройка сборки**: своя иконка (любая картинка) или цвет блока, название, смена версии и загрузчика, размер окна, память, JVM, Java.
- **.mrpack**: экспорт сборки (моды с Modrinth записываются ссылками, остальное кладётся внутрь) и импорт .mrpack и сборок CurseForge из файла.
- **Моды из файла**: кнопка «Из файла» или перетаскивание .jar и .zip на вкладку «Контент». Zip распознаётся как мод, ресурспак, шейдер или архив с модами.
- **Обновление модов**: кнопка «Обновления» на вкладке «Контент» ищет новые версии по хэшам файлов (Modrinth) и по меткам установки (CurseForge), заменяет выбранные, сохраняя состояние «выключен».
- **Проверка сборки**: кнопка «Проверка» читает метаданные модов (Fabric, Quilt, Forge, NeoForge) и находит неподходящий загрузчик или версию игры, недостающие зависимости (их можно доустановить одной кнопкой), заявленные несовместимости и дубликаты.
- **Скриншоты**: вкладка со всеми снимками сборки, просмотр, копирование в буфер, показ в папке и удаление в корзину.
- **Журналы**: текущая сессия, latest.log, старые журналы и краш-репорты; фильтр по уровню, поиск, копирование и «Для отчёта» (версия, список модов и конец журнала).
- **Страница проекта внутри лаунчера**: описание, версии с установкой нужной, галерея и ссылки; открывается по названию в каталоге.
- **Иконки и названия** модов, ресурспаков и шейдеров берутся из самих файлов и кэшируются.
- **Лёгкий на ресурсы**: анимации отключаются, пока идёт игра или окно свёрнуто; поток журнала игры собирается пачками; есть экономный режим.
- **Темы**: Самурай (по умолчанию), Полночь, День, OLED, Северное сияние, Закат, Сакура, Лес, Океан, Скалк, Пышные пещеры, Вишнёвая роща.

## Запуск

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start
```

Установщик: `npm run dist:win`, `npm run dist:mac` или `npm run dist:linux`; результат в `dist/`.

**Если `npm start` пишет «Electron failed to install correctly».** Новые версии npm блокируют установочные скрипты зависимостей, и Electron не скачивается. В проекте это обходится само (скрипты `postinstall` и `prestart` докачивают Electron). Если не помогло, выполните вручную:

```bash
node node_modules/electron/install.js
npm start
```

## Установщик для Windows (exe)

Готовый установщик собирается командой `npm run dist:win`, результат появляется в папке `dist` (`Onyx-Setup-<версия>.exe`). Node.js на компьютере, где его запускают, не нужен. Установщик ставит Оникс в профиль пользователя, создаёт ярлыки на рабочем столе и в меню «Пуск» и умеет удаляться.

Windows может показать предупреждение SmartScreen («Неизвестный издатель»), потому что установщик не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Без своего компьютера с Node.js собрать exe можно на GitHub: запустите workflow «Сборка установщика для Windows» (вкладка Actions → Run workflow), готовый exe появится в разделе Artifacts. Если создать тег вида `v0.3.3`, exe прикрепится к релизу.

## Автообновление лаунчера

Оникс берёт обновления из релизов репозитория на GitHub (`Lordome42/onyx-launcher`, адрес записан в `package.json`: поле `onyxUpdateRepo` и `build.publish`). При запуске он проверяет, есть ли новая версия (проверку можно выключить в «Настройки → О лаунчере»), и показывает плашку внизу окна с кнопками «Обновить» и «Позже». Скачивание идёт в фоне, потом достаточно нажать «Перезапустить». Работает только в установленной версии, а репозиторий должен быть публичным.

### Выпуск обновления

1. Поднимите `version` в `package.json` (например, `0.3.3`) и закоммитьте.
2. Создайте и отправьте тег с такой же версией:
   ```bash
   git tag v0.3.3
   git push origin v0.3.3
   ```
3. Workflow «Сборка установщика для Windows» (`.github/workflows/build-windows.yml`) соберёт установщик и приложит к релизу `Onyx-Setup-<версия>.exe`, `latest.yml` и `.blockmap`. Все три файла обязательны для автообновления. Установленные лаунчеры увидят новую версию при следующем запуске.

Вручную собрать установщик для проверки можно командой `npm run release`, файлы появятся в папке `release/`.

## CurseForge

CurseForge требует личный ключ API. Он бесплатный: console.curseforge.com → API keys. Вставьте его в «Настройки → CurseForge». Если автор мода запретил скачивание вне сайта CurseForge, лаунчер не обходит это ограничение и предлагает открыть страницу мода.

## Данные

`%APPDATA%\.onyx-launcher` на Windows, `~/Library/Application Support/.onyx-launcher` на macOS, `~/.config/.onyx-launcher` на Linux. Внутри: instances, versions, libraries, assets, runtimes, cache, settings.json, accounts.json.

## Код

```
src/main/       основной процесс: auth, minecraft, instances, modrinth, curseforge, local (иконки, миры, серверы), net, store
src/renderer/   интерфейс без сборщика: styles.css (темы), js/pages/*
tools/          демо-данные и скрипт скриншотов
```

## Своя тема

Скопируйте блок `[data-theme='ocean']` в `src/renderer/styles.css`, поменяйте цвета и добавьте запись с тем же `id` в `src/renderer/js/themes.js`.
